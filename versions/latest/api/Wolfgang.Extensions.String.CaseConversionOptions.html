    Class CaseConversionOptions

    How ToCamelCase, ToKebabCase, ToPascalCase, ToSnakeCase and SplitWords find the words of a string. A new instance holds the rules the conversions use when no options are given.

    using Wolfgang.Extensions.String;

var options = new CaseConversionOptions
{
    Punctuation = PunctuationHandling.Keep,
    Boundaries = WordBoundaries.Separators,
};

var snake = "Hello, World!".ToSnakeCase(options);
// snake == "hello,_world!"

    WordSplitter

    A function that finds the words of the string in place of the built-in rules, or null (the default) to use the built-in rules.

    Declaration
    public Func<string, IEnumerable<string>>? WordSplitter { get; set; }
    Property Value
    Type Description
    Func<string, IEnumerable<string>>
    Remarks

    When it is set, Punctuation and Boundaries are not used: the conversion cases and joins exactly the words the function returns, in the order it returns them. The sequence is enumerated once. A null or empty word is skipped.
