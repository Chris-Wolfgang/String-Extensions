    Enum WordBoundaries

    The things that divide one word from the next when a case conversion splits a string.

    Namespace: Wolfgang.Extensions.String
    Assembly: Wolfgang.Extensions.String.dll
    Syntax
    [Flags]
public enum WordBoundaries
    Remarks

    Separators, Delimiters and ControlCharacters only make a difference together with Keep: when punctuation is dropped, every character that is not a letter or a digit ends the word whatever is chosen here.

    Fields

    Name Description
    All

    All of the above. This is what the conversions use when no options are given.
    CaseChanges

    A change of case inside an identifier: an upper-case letter after a lower-case letter or a digit, and the last upper-case letter of a run that a lower-case letter follows.
    ControlCharacters

    A character for which IsControl(char) is true, such as a tab or a line feed.
    Delimiters

    An underscore or a dash, the delimiters of snake case and kebab case.
    None

    Nothing divides words except what Drop removes.
    Separators

    A character for which IsSeparator(char) is true: a space, a no-break space, a line or paragraph separator.
