    Enum AcronymHandling

    How ToCamelCase and ToPascalCase case a word that is written entirely in upper case, such as SKU in SKUCode.

    Namespace: Wolfgang.Extensions.String
    Assembly: Wolfgang.Extensions.String.dll
    Syntax
    public enum AcronymHandling

    Fields

    Name Description
    AsWord

    The acronym is cased like any other word: SKUCode becomes SkuCode. This is what the conversions do when no options are given.
    Preserve

    A word that has no lower-case letter is left as it is wherever a word is capitalized: SKUCode stays SKUCode in Pascal case. The first word of a camel-case result is still lower-cased: skuCode.
